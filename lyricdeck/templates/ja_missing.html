Japanese is not installed

Japanese support is optional, because its dictionary for splitting words adds about 250 MB. To turn it on:

  1. Install the Japanese packages: uv sync --extra ja (add --extra claude too if you use Claude with an API key).
  2. Download the Japanese dictionary (JMdict, about 11 MB): uv run flask --app lyricdeck init-data --lang ja
  3. Restart LyricDeck and open this page again.

Russian keeps working either way; the two languages never share songs, known words or decks.
